# BEMiner
Distance sampling and bootstrap analyses on Black-eared Miner data

1_Nest-vs-First - Distance sampling analysis on (i) distance-to-nest VS (ii) distance-to-first-bird-detected data.
2_PoolData - Distance sampling analysis across the distance-to-nest data across time periods (2000, 2007 and 2015).
3_Clusters - Distance sampling analysis on the latest cluster distance data (2015-2016); note the new, higher density/abundance estimates compared to the distance-to-nest data.
4_Effort - Bootstrapping analysis to determine minimum allowable survey effort while preserving precision. Based on this analysis, I recommend an effort of no lower than 450 – 500 km.

(Bootstrapping functions in R folder)
